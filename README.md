# Orange Tennis Club

Local demo of the Orange Tennis Club site: the public homepage, court booking, member signup, and a staff admin page.

## Run

```bash
python3 server.py
```

Then open http://127.0.0.1:8080/homepage.html

## Staff login

- Username: `admin`
- Password: `orange2026`

Members sign up from Kayıt ol. Passwords in `data.json` are stored as hashes.
